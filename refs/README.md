## Правила для референсов
- Внутри одного материала все картинки одной серии: один фон, один язык предметов (см. `ILLUSTRATIONS.md`, раздел 3a).
- Это образцы стиля, не клипарт: не вставлять в готовые материалы как есть и не копировать композицию.
- На рефах-постах есть набранный текст: модели его не воспроизводить.
- Не удалять и не переименовывать файлы: на id узлов ссылаются инструкции.
